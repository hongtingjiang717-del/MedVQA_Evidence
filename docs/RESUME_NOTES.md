# 简历写法（完整项目上线并测试网页后采用）

**MedVQA-Evidence｜医学多模态视觉问答与视觉依赖评测系统**  
*Python / PyTorch / Transformers / Qwen3-VL / Hugging Face Datasets / Gradio*

- 基于公开Qwen3-VL-2B-Instruct与SLAKE数据集完成医学影像视觉问答模型部署，构建图像+问题与仅文本两种输入的可复现配对评测流程，并完成图像级数据泄漏审计。

- 构建Gradio交互原型，展示真实医学图像问答、无图像对照及结果看板，分析模型视觉依赖与医学同义答案导致的自动评测偏差。
