# MedVQA-Evidence｜Qwen3-VL医学视觉问答中视觉信息增益的探索性评测

## 研究问题

当医学视觉语言模型回答影像相关问题时，提供实际图像是否比仅提供问题文字带来额外预测增益？

## 方法

- 数据集：SLAKE英文版（`mdwiratathya/SLAKE-vqa-english`），验证集。
- 模型：`Qwen/Qwen3-VL-2B-Instruct`，使用官方公开预训练权重；无领域微调。
- 样本：随机种子42；150条配对医学视觉问答，对应73张唯一影像。
- 条件：A. 原始影像+问题；B. 仅问题文字。每个问答在两个条件下使用同一问题及标准答案。
- 指标：Exact Match（规范化答案完全匹配），Token-F1（词级F1）。
- 统计：以唯一医学影像为簇进行Bootstrap重采样估计条件差异的95%区间（探索性区间）。
- 质量控制：用户已执行跨train/validation/test的图像哈希交叉检查，报告的交叉值均为0；此检查不排除近似重复及模型预训练污染。

## 结果

| 指标 | 原图+问题 | 仅文本 |
|---|---:|---:|
| 问答数量 | 150 | 150 |
| Exact Match | 47.33% (71/150) | 35.33% (53/150) |
| Token-F1 | 0.5072 | 0.3807 |

- EM绝对差异：+12.00个百分点；影像聚类Bootstrap 95%区间：[4.14, 19.85]个百分点。
- Token-F1差异：+0.1265；影像聚类Bootstrap 95%区间：[0.0497, 0.2008]。
- 在配对题目中：26条原图正确而文本错误；8条原图错误而文本正确；116条条件间EM一致。
- 两个条件的回答文字发生变化：78/150（52%）。
- 150条问答全部完成配对，没有缺失结果。以上来自用户真实 `day4_validation_summary.json`。

## 解释

在这一组SLAKE验证集问答上，模型获得真实图像后EM和Token-F1均提高；按医学影像聚类估计的差异区间未包含0，提示正向视觉信息增益。不过结果仍属于探索性验证，不能推断为普适医疗视觉理解能力或临床可靠性。

## 局限与后续

1. 严格文本匹配会把医学同义答案视为错误，如 `Transverse Plane` 与 `axial`。
2. 部分SLAKE原始答案和问题类型存在标签规范性问题；尚未完成系统人工医学语义复核。
3. 同张影像可对应多条问答，已进行图像聚类不确定性估计，但单一数据集的外推有限。
4. 当前结果来自验证集，尚无锁定方案的独立测试集评测或跨医院外部验证。
5. 模型是通用多模态基础模型，不具备本项目未开发的病灶目标检测、分割、临床诊断能力。
6. 之前50条wrong_image探索实验缺少替换图像的来源记录，因此不作为此正式结果的一部分。

## 面向企业的工程价值

部署真实开源视觉语言模型、搭建医学问答数据处理流水线、基于统一样本进行消融、支持断点续跑、检测图像级重复、实现按影像聚类的统计评估，并提供Gradio实时交互展示。

> 所有指标均为**验证集**上的真实项目结果，不可改写成“临床准确率”或“测试集准确率”。
